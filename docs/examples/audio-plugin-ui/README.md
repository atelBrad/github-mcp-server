# Atlas Audio Studio UI Mock

This standalone prototype demonstrates a modern control surface for an audio plugin. Open `index.html` in your browser to explore the experience:

- Drag-and-drop audio loading with waveform visualization
- Quick presets that reconfigure effect chains and parameter ranges
- Real-time metering and spectrum analysis powered by the Web Audio API
- Session utilities such as looping, transport scrubbing, and mixdown export mock flows

The mock uses plain HTML, CSS, and vanilla JavaScript so it can be hosted from any static web server or opened directly from disk. No build step is required.
